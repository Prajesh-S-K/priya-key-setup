PRIYA KEY

Set up your key in a few minutes

Start here: the key cannot install the app by itself

Plugging the key in does not install anything. First open this page on the computer or phone you will use, install the app from it, and only then plug the key in. You approve every step; nothing installs by itself.

Windows PCWindows 10 or 11, 64-bit Android phoneAndroid 11 or newer

Windows version 0.9.0-rc.4

Download the complete Windows package (208.5 MB)

One ZIP with everything Windows needs: the installer, WinFsp and the offline Microsoft WebView2 runtime installer. Choose this if you are unsure, or if the PC is offline or runs Windows 10.

Already on Windows 11 with a normal Microsoft Edge? The installer alone is smaller: installer only (2.1 MB). It includes WinFsp but needs the WebView2 runtime to be present already.

Windows 11 “Smart App Control”: if it is switched on, Windows may block this installer outright, because the app is not signed with a commercial certificate. Unlike the SmartScreen warning, Smart App Control has no “Run anyway” button. Your choices: use a PC where it is off (Windows 10, or a Windows 11 PC that has it off); or switch it off knowingly in Windows Security ▸ App & browser control ▸ Smart App Control settings — Microsoft has historically not allowed it to be switched back on without resetting Windows, so only do this if you accept that. The Android app is not affected.
  1. Extract the ZIP first (right-click ▸ Extract All…) — do not run the setup from inside the ZIP preview, because it must sit next to its redist folder. Then open PriyaKey-Setup-0.9.0-rc.4.exe.
  2. Windows asks for permission to make changes (administrator): choose Yes. The installer adds a small file-system driver called WinFsp (it shows your unlocked folders as a drive) and checks for the Microsoft WebView2 runtime that draws the window.
  3. If Windows shows the blue SmartScreen box “Windows protected your PC” (the app is not commercially signed): choose More info and then Run anyway — but only if the checksum below matches. (This does not apply to Smart App Control, see above.)
  4. When the installer asks, leave “Start with Windows” unticked unless you want the key icon in the tray after login. A desktop shortcut is optional; the Start menu entry Priya Key is always there.
  5. Now plug the key into a USB port with a data cable. Windows may take a minute to set up the USB serial driver (it may use Windows Update).
  6. Open Priya Key from the Start menu. A short first-time check lists anything missing.
  7. Choose a four-digit PIN, press the BOOT button on the key when asked, and write the recovery code on paper. Keep it separate from the key.

Permissions and prompts on Windows

  • Administrator approval — once, to install the program and WinFsp.
  • The app itself never connects to the internet and has no server. Installing the complete package needs nothing else to be downloaded. With installer only, a PC without the WebView2 runtime (some Windows 10 PCs) needs it from Microsoft first.
  • The USB serial driver for the key is normally supplied by Windows itself (Windows Update may be used the first time). It is not in the package; if Windows cannot find it, see Troubleshooting.

Android version 0.9.0-rc.4

Download the Android app (7.9 MB)

  1. Open the downloaded file. Android will say it blocks installs from this source: choose Settings and allow “Install unknown apps” for the browser or Files app you used. You can turn it off again afterwards.
  2. Choose Install, then Open. The first-time check lists what is still needed.
  3. Plug the key in with a USB-C cable (or an OTG adapter) that carries data. Android asks “Allow Priya Key to access the USB device?” — choose Allow.
  4. Allow notifications when asked. Android requires a visible notice while the key stays connected; it has a Lock all button.
  5. Recommended: open Battery in the first-time check and allow unrestricted background use; some phones otherwise stop the connection when the screen is off, which locks your folders.
  6. Choose a four-digit PIN, press the BOOT button on the key when asked, and write the recovery code on paper.

Permissions on Android

  • USB device access — only for the key.
  • Notifications and foreground service — to show that the key is connected.
  • Folders — the app only sees folders you pick with Android's own folder picker. It does not ask for contacts, location, camera, microphone or general storage access, and it has no internet permission.
Important: encrypted folders on Android are stored inside the app. Uninstalling the app or clearing its data permanently deletes them. The recovery code cannot bring back a deleted vault file. Use More ▸ Back up encrypted folder… and keep the backups somewhere else. The app never deletes your original files by itself.

After setup

  • Discreet mode (Settings, off by default): when the key is unplugged everything locks and the app closes its window (and its tray icon on Windows). It is not invisibility — the app remains in your installed apps and the key remains visible to the system as a USB device. Plugging the key back in, or opening the app yourself, always asks for the PIN again. On Android the app is designed to be started by the USB prompt when the key is plugged in, but that relaunch is still pending verification on a real phone — open the app by hand if it does not appear.
  • Opening the app by hand always works: Windows Start menu ▸ Priya Key; Android app drawer ▸ Priya Key.
  • Privacy button: press BOOT once to lock everything at once; press it again to bring the key back, then enter the PIN.
Troubleshooting
  • “Plug in the key” stays on screen: try another cable (many only charge) or port.
  • Windows: the download or installer is blocked with no way to continue — that is Smart App Control (see the Windows section). Use another PC or switch it off knowingly.
  • Windows: no drive appears after unlocking — run the installer again (it reinstalls WinFsp if missing).
  • Android: no USB prompt — unplug and replug, open the app, and use the first-time check ▸ “Ask now”.
  • Wrong PIN too often: the key makes you wait (5 seconds, then longer). That is by design.
